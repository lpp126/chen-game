# 需求文档

## 1. 应用概述

- **应用名称**：陈添祥的平行世界：24帧人生
- **应用描述**：手机竖屏粉丝应援游戏，包含首页、主页（关卡选择）与节奏小游戏关卡。首页展示陈添祥相关元素与游戏名称，主页展示闯关进度与关卡选择，游戏关卡中屏幕上有2条音轨，音符从上向下飞落，玩家在音符到达判定线时点击按压对应音轨底部的奶瓶模拟喂奶，将饱食度推至100%完成通关，并根据表现获得1-3星评级。

- 页面底部居中展示两行小字（字号适中，清晰可读但不抢眼）：
  - 第一行：陈添祥24周岁生日应援游戏
  - 第二行：Copyright ©添_星辉 | 陈添祥

### 2.5 游戏主页（第一关）

#### 2.5.1 顶部状态栏

- **饱食度进度条**：横向进度条，范围0%-100%，随节拍成功/失败实时增减
- **收集音符数**：显示当前已收集的「音符奶滴」数量
- **当前连击数**：显示连续成功按压次数，错拍后归零

#### 2.5.2 双轨道音符区

- 屏幕中央纵向排列2条平行音轨，分别对应左侧奶瓶与右侧奶瓶
- 音符从每条音轨顶部向下飞落，速度与BGM节拍同步
- 音符外观为圆形奶滴图标，柔光水彩风格，奶油白/淡蓝/浅桃色
- 音符到达底部判定线时为最佳按压时机

#### 2.5.3 判定线

- 位于音轨底部偏上位置，横贯两条音轨
- 判定线在节拍到来时有轻微发光/脉动效果，辅助玩家感知时机
- 判定区间：
  - **Perfect**：音符中心与判定线重合时按压（误差极小）
  - **Good**：音符接近判定线时按压（误差在允许范围内）
  - **Oops**：音符已过判定线或未到达时按压，或音符经过判定线时未操作

#### 2.5.4 底部奶瓶交互区

**奶瓶布局**
- 屏幕底部左右各一个玻璃奶瓶，分别对应左右两条音轨
- 透明玻璃质感，奶瓶内奶液液位随饱食度同步变化（饱食度越高液位越低）
- 奶瓶周围有脉动光圈，与BGM节拍同步扩张收缩，光圈最大时为最佳按压时机

**按压交互**
- 玩家点击按压对应音轨底部的奶瓶触发喂奶操作
- 成功按压时触发奶液流出动画，宝宝表情切换为满足微笑
- 错拍/漏拍时画面轻微震动，宝宝表情切换为难受皱眉

**宝宝角色**
- 两个奶瓶中间展示宝宝角色，表情随游戏状态变化：
  - 正常状态：安静、微闭眼
  - 成功按压：满足微笑
  - 错拍/呛奶：难受皱眉
  - 安抚时刻：哭泣/委屈

**反馈文字**
- 成功时在对应奶瓶上方浮现「Perfect」或「Good」文字，短暂显示后消散
- 失败时浮现「Oops...」文字，伴随画面震动效果

**音符奶滴收集**
- 每次节拍成功后，从对应奶瓶周围随机飘出1个「音符奶滴」图标
- 玩家可点击收集，未点击则在2秒后自动消失
- 收集数量每达到10个时触发彩蛋：播放额外哼唱旋律片段，并奖励饱食度+5%

**操作提示**
- 首次进入游戏时显示「跟随节拍，点击对应奶瓶喂奶」提示文字，首次成功操作后消失

#### 2.5.5 安抚时刻覆盖层

**触发条件**：连续错拍3次

**进入安抚时刻**
- BGM音量降低至30%，画面整体变柔（亮度降低、色调偏暖）
- 宝宝表情切换为哭泣/委屈
- 屏幕中央出现引导提示：「轻轻安抚宝宝，顺时针画圈3秒」
- 出现圆形轨迹引导图示
- 安抚时刻期间暂停音符飞落与节拍判定

**安抚操作**
- 玩家在屏幕上顺时针画圈，持续3秒
- 画圈进度以圆形进度环实时展示
- 3秒完成后：
  - 宝宝表情恢复安静
  - BGM恢复100%音量
  - 画面恢复正常
  - 连续错拍计数归零，音符从当前节拍位置继续飞落
  - 播放安抚成功音效：满足的「嗯～」声
- 若画圈中断（手指离开屏幕），进度重置，需重新开始

---

### 2.6 通关结算页（第一关）

**触发条件**：饱食度达到100%

**展示内容**
- 通关标题：「宝宝喝饱啦！」
- 星级评定（1-3星），评定规则见业务规则章节
- 数据汇总：
  - 节拍准确率（Perfect+Good次数 / 总音符数）
  - 音符奶滴收集数量
  - 是否触发安抚时刻（是/否）
- 「再玩一次」按钮：重置游戏，返回开始页
- 「返回主页」按钮：返回主页（关卡选择）

## 3. 业务规则与逻辑

### 3.1 BGM与音符同步规则

- BGM为陈添祥歌曲《我们》
- 音符飞落速度与BGM节拍严格同步，音符到达判定线的时刻对应BGM重拍
- 脉动光圈扩张周期与BGM重拍严格同步
- 安抚时刻期间BGM降至30%音量，安抚成功后恢复100%音量

### 3.2 饱食度变化规则

| 操作结果 | 饱食度变化 |
|---------|----------|
| Perfect | +5% |
| Good | +3% |
| Oops（错拍/漏拍） | -2% |
| 音符奶滴彩蛋触发（每10个） | +5%（额外奖励） |
| 饱食度最低值 | 0%（不低于0%） |

### 3.3 星级评定规则

| 星级 | 条件 |
|------|------|
| 3星 | 准确率 ≥ 90% 且 未触发安抚时刻 且 音符收集数 ≥ 总飘出数的60% |
| 2星 | 准确率 ≥ 70% 且 未同时满足3星条件 |
| 1星 | 完成通关（饱食度达100%），不满足2星条件 |

### 3.4 连击规则

- 连续Perfect或Good计入连击数
- 任意一次Oops后连击数归零
- 连击数仅作展示，不影响饱食度计算

### 3.5 关卡解锁规则

- 本期仅第一关「听，奶瓶里的摇篮曲」为可进入状态
- 其余关卡在主页显示为待解锁状态，不可点击进入
- 通关第一关后，主页对应关卡节点更新为已通关并展示所获星级

## 4. 音效规范

| 场景 | 音效描述 |
|------|----------|
| 游戏BGM | 陈添祥《我们》，循环播放 |

## 5. 美术风格规范

- **整体风格**：柔光水彩风格，干净、治愈、不幼稚
- **主色调**：奶油白、淡蓝、浅桃色
- **奶瓶**：透明玻璃质感，左右各一，可见内部奶液液位
- **音轨**：2条纵向平行轨道，简洁线条，与整体水彩风格融合
- **背景**：朦胧婴儿房剪影
- **屏幕方向**：手机竖屏（Portrait）
- **光效**：柔光漫射，避免强对比或高饱和色

---

## 6. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 饱食度降至0% | 保持0%，不继续扣减，游戏继续 |
| 安抚时刻中途手指离开屏幕 | 画圈进度重置，需重新顺时针画圈3秒 |
| 音符奶滴未被点击 | 2秒后自动消失，不计入收集数 |
| 安抚时刻期间音符状态 | 暂停音符飞落与节拍判定，安抚成功后从当前节拍位置继续 |
| 游戏中途退出 | 不保存进度，返回开始页 |
| 彩蛋触发时饱食度已接近100% | 奖励饱食度叠加后若超过100%则直接触发通关 |
| 同时点击两个奶瓶 | 分别独立判定，各自触发对应音轨的判定逻辑 |
| 点击待解锁关卡 | 无响应或提示「敬请期待」，不可进入 |
